## विहंगावलोकन | विहंगावलोकन
**एआय-राउटर** बुद्धिमान एलएलएम एपीआय व्यवस्थापनासाठी उत्पादन-तयार पायथन टूलकिट आहे. हे स्वयंचलित लोड बॅलन्सिंग, फॉलबॅक, कॉस्ट ऑप्टिमायझेशन आणि व्यापक मेट्रिक्ससह एकाधिक एआय प्रदात्यांमध्ये (ओपनएआय, अँथ्रोपिक, डीपसीक, गुगल आणि बरेच काही) विनंत्या रूट करण्यासाठी एक एकीकृत इंटरफेस प्रदान करते.
**एआय-राउटर** एलएलएम एपीआय विनंत्या हुशारीने व्यवस्थापित करण्यासाठी एक उत्पादन-ग्रेड पायथन टूलकिट आहे. हे एकाधिक एआय प्रदात्यांमध्ये (ओपनएआय, अँथ्रोपिक, डीपसीक, गुगल इ.) बुद्धिमान रूटिंगला समर्थन देणारा एक एकीकृत इंटरफेस प्रदान करते, ज्यामध्ये स्वयंचलित लोड बॅलन्सिंग, फेलओव्हर, कॉस्ट ऑप्टिमायझेशन आणि व्यापक मेट्रिक मॉनिटरिंग आहे.

## वैशिष्ट्ये | 功能特性
### 🧠 स्मार्ट राउटर | 智能路由器
- **मल्टी-प्रोवाइडर**: ओपनएआय, अँथ्रोपिक, डीपसीक, गूगल जेमिनी, एक्स्टेंसिबल
- **धोरणे**: राऊंड-रॉबिन, भारित, सर्वात कमी-विलंब, सर्वात कमी खर्च, शब्दार्थ, अनुकूली
- **कॅशिंग**: एलआरयू + शब्दार्थ समानता डेडअप कॅशे
- **फॉलबॅक**: सर्किट ब्रेकर, स्वयंचलित पुनर्प्रयत्न, बहु-स्तरीय फॉलबॅक चेन
- **दर मर्यादित करणे**: टोकन बकेट अल्गोरिदम, प्रत्येक प्रदाता आणि जागतिक मर्यादा
- **मेट्रिक्स**: अलर्टसह विलंबता, खर्च, यश दर ट्रॅकिंग
### 📚 आरएजी पाइपलाइन | RAG 管线








- **चंकिंग**: निश्चित आकार, वाक्य, परिच्छेद, पुनरावृत्ती, मार्कडाउन, स्लाइडिंग विंडो
- **एम्बेडिंग**: ओपनएआय, वाक्य-ट्रान्सफॉर्मर, एक्स्टेंसिबल बॅकएंड
- **पुनर्प्राप्ती**: संकरित (बीएम 25 + वेक्टर), आरआरएफ फ्यूजन, भारित संयोजन
- **पुनर्क्रमांकन**: स्कोअर-आधारित, एमएमआर विविधता, क्रॉस-एन्कोडर, एलएलएम न्यायाधीश
### 🤖 एजंट फ्रेमवर्क | Agent 框架
- **रिअॅक्ट एजंट**: रीजनिंग + टूलच्या वापरासह अॅक्टिंग लूप
- **टूल सिस्टम**: डेकोरेटर-आधारित नोंदणी, जेएसओएन स्कीमा, प्रमाणीकरण
- **ऑर्केस्ट्रेशन**: अनुक्रमिक, समांतर, वादविवाद, व्यवस्थापक-कामगार नमुने
- **मेमरी**: अल्पकालीन, दीर्घकालीन, एपिसोडिक, कार्यरत मेमरी
### 📊 मूल्यांकन | 评估
- **स्कोअरिंग**: BLEU, ROUGE-1/2/L, शब्दार्थ समानता, F1, अचूक जुळणी
- **बेंचमार्किंग**: विलंबता, थ्रूपुट, खर्च, लोड अंतर्गत यश दर
### 🌐 एपीआय सर्व्हर | API 服务
- **फास्टएपीआय**: ओपनएआय-सुसंगत INLINE14, एम्बेडिंग, आरएजी, एजंट एंडपॉइंट्स
- **मिडलवेअर**: लॉगिंग, दर मर्यादित, विनंती आयडी, वेळ, सीओआरएस
