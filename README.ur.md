## جائزہ | جائزہ
**ai-router** ایک پروڈکشن ریڈی پائتھون ٹول کٹ ہے جو ذہین LLM API مینجمنٹ کے لیے ہے۔ یہ متعدد AI فراہم کنندگان (OpenAI، Anthropic، DeepSeek، Google، اور دیگر) کے درمیان درخواستوں کو روٹ کرنے کے لیے ایک متحدہ انٹرفیس فراہم کرتا ہے، جس میں خودکار لوڈ بیلنسنگ، بیک اپ (بیک اپ)، لاگت کی اصلاح اور جامع میٹرکس شامل ہیں۔
**ai-router** ایک پروڈکشن گریڈ پائتھن ٹول کٹ ہے جو LLM API درخواستوں کو ذہانت سے منظم کرتا ہے۔ یہ ایک متحدہ انٹرفیس فراہم کرتا ہے جو متعدد AI فراہم کنندگان (OpenAI، Anthropic، DeepSeek، Google وغیرہ) کے درمیان ذہین روٹنگ کی حمایت کرتا ہے، جس میں خودکار لوڈ بیلنسنگ، فیل اوور، لاگت کی اصلاح، اور جامع میٹرک مانیٹرنگ شامل ہیں۔

## خصوصیات | 功能特性
### 🧠 اسمارٹ روٹر | 智能路由器
- **ملٹی پرووائیڈر**: اوپن اے آئی، انتھروپک، ڈیپ سیک، گوگل جیمینی، ایکسٹینسیبل
- **حکمت عملیاں**: راؤنڈ رابن، ویٹڈ، سب سے کم لیٹنسی، سب سے کم لاگت، معنوی اور موافق
- **کیشنگ**: LRU + معنوی مماثلت ڈیڈ اپ کیش
- **فال بیک**: سرکٹ بریکر، خودکار دوبارہ کوشش، ملٹی لیول فال بیک چینز
- **ریٹ لیمیٹنگ**: ٹوکن بکٹ الگورتھم، فی فراہم کنندہ اور عالمی حدود
- **میٹرکس**: لیٹنسی، لاگت، کامیابی کی شرح کی نگرانی الرٹس کے ساتھ
### 📚 RAG پائپ لائن | RAG 管线








- **چنکنگ**: مقررہ سائز، جملہ، پیراگراف، ریکرسیو، مارک ڈاؤن، سلائیڈنگ ونڈو
- **ایمبیڈنگ**: اوپن اے آئی، جملہ ٹرانسفارمرز، ایکسٹینسیبل بیک اینڈز
- **بازیابی**: ہائبرڈ (BM25 + ویکٹر)، RRF فیوژن، وزنی امتزاج
- **ری رینکنگ**: اسکور پر مبنی، MMR تنوع، کراس انکوڈر، LLM جج
### 🤖 ایجنٹ فریم ورک | Agent 框架
- **ری ایکٹ ایجنٹ**: آلے کے استعمال کے ساتھ استدلال + عمل کرنے کا لوپ
- **ٹول سسٹم**: ڈیکوریٹر پر مبنی رجسٹریشن، JSON اسکیما، ویلیڈیشن
- **آرکسٹریشن**: مسلسل، متوازی، مباحثہ، مینیجر-ورکر پیٹرن
- **یادداشت**: قلیل مدتی، طویل مدتی، قسط وار، ورکنگ میموری
### 📊 جائزہ | 评估
- **اسکورنگ**: BLEU، ROUGE-1/2/L، معنوی مماثلت، F1، بالکل مماثلت
- **بینچ مارکنگ**: لیٹنسی، تھروپٹ، لاگت، لوڈ کے تحت کامیابی کی شرح
### 🌐 API سرور | API 服务
- **FastAPI**: اوپن اے آئی کے مطابق INLINE14، ایمبیڈنگز، RAG، ایجنٹ اینڈ پوائنٹس
- **مڈل ویئر**: لاگنگ، ریٹ لمٹنگ، ریکویسٹ آئی ڈی، ٹائمنگ، CORS
