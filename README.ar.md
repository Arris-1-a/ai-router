## نظرة عامة | نظرة عامة
**ai-router** هو مجموعة أدوات بايثون جاهزة للإنتاج لإدارة واجهات برمجة تطبيقات نماذج اللغة الكبيرة الذكية. يوفر واجهة موحدة لتوجيه طلبات التوجيه عبر مزودي ذكاء اصطناعي متعددين (OpenAI، Anthropic، DeepSeek، Google، وغيرهم) مع توازن تلقائي للحمل، ونظام احتياطي، وتحسين التكاليف، ومقاييس شاملة.
**ai-router** هو مجموعة أدوات بايثون إنتاجية لإدارة طلبات واجهات برمجة تطبيقات نماذج اللغة الكبيرة بذكاء. يوفر واجهة موحدة تدعم التوجيه الذكي عبر مزودي ذكاء اصطناعي متعددين (OpenAI، Anthropic، DeepSeek، Google، وغيرها)، مع موازنة تلقائية للحمل، وتجاوز الحمل، وتحسين التكاليف، ومراقبة شاملة للمقاييس.

## الميزات | 功能特性
### 🧠 راوتر ذكي | 智能路由器
- **مزودي الخدمة المتعددة**: OpenAI، Anthropic، DeepSeek، Google Gemini، قابل للتوسعة
- **الاستراتيجيات**: الدوران الدائري، موزون، أقل زمن تأخير، أقل تكلفة، دلالي، تكيفي
- **التخزين المؤقت**: ذاكرة تخزين مؤقت مقسوعة ب LRU + التشابه الدلالي
- **الرجوع الاحتياطي**: قاطع دائرة، إعادة محاولة تلقائية، سلاسل احتياطية متعددة المستويات
- **تحديد المعدل**: خوارزمية دلو الرموز، لكل مزود وحدود عالمية
- **المقاييس**: تتبع التأخير، التكلفة، معدل النجاح مع التنبيهات
### 📚 خط أنابيب RAG | RAG 管线








- **التقسيم**: حجم ثابت، جملة، فقرة، تكراري، تخفيف، نافذة منزلقة
- **التضمين**: OpenAI، محولات الجمل، الخلفيات القابلة للتوسعة
- **الاسترجاع**: هجين (BM25 + متجه)، اندماج RRF، تركيبة موزونة
- **إعادة الترتيب**: تعتمد على الدرجات، تنوع MMR، ترميز متقاطع، حكم LLM
### 🤖 إطار عمل الوكيل | Agent 框架
- **عامل ReAct**: حلقة التفكير + الفعل باستخدام الأدوات
- **نظام الأدوات**: تسجيل قائم على الديكور، مخطط JSON، التحقق من الصحة
- **التنسيق**: أنماط متسلسلة، متوازية، مناظرية، وأنماط مدير-عامل
- **الذاكرة**: ذاكرة عاملة قصيرة المدى، طويلة الأمد، حلقية،
### 📊 تقييم | 评估
- **التسجيل**: BLUE (BLUE)، ROUGE-1/2/L، تشابه دلالي، F1، تطابق دقيق
- **المقارنة المرجعية**: التأخير، معدل الإنتاجية، التكلفة، معدل النجاح تحت الحمل
### 🌐 خادم واجهة برمجة التطبيقات | API 服务
- **FastAPI**: INLINE14، وتضمينات، وRAG، ونقاط نهاية وكلاء متوافقة مع OpenAI
- **الوسيط**: التسجيل، تحديد المعدل، معرف الطلب، التوقيت، CORS
