## Обзор | Обзор
**ai-router** — это готовый к продакшн набор инструментов на Python для интеллектуального управления LLM API. Он предоставляет единый интерфейс для маршрутизации запросов между несколькими провайдерами ИИ (OpenAI, Anthropic, DeepSeek, Google и другими) с автоматической балансировкой нагрузки, запасным вариантом, оптимизацией затрат и комплексными метриками.
**ai-router** — это производственный набор инструментов на Python для интеллектуального управления запросами LLM API. Он предоставляет единый интерфейс, поддерживающий интеллектуальную маршрутизацию между несколькими провайдерами ИИ (OpenAI, Anthropic, DeepSeek, Google и др.), включая автоматическую балансировку нагрузки, отказоустойчивость, оптимизацию затрат и комплексный мониторинг метрик.

## Особенности | 功能特性
### 🧠 Умный роутер | 智能路由器
- **Мульти-провайдер**: OpenAI, Anthropic, DeepSeek, Google Gemini, расширяемый
- **Стратегии**: Круговой системный, взвешенный, минимальная задержка, наименьшая стоимость, семантический, адаптивный
- **Кэширование**: LRU + кэш семантического сходства dedup
- **Запасной вариант**: автоматический выключатель, автоматическая повторная попытка, многоуровневые цепочки резерва
- **Ограничение скорости**: алгоритм токен-бакета, для каждого провайдера и глобальные лимиты
- **Метрики**: Задержка, стоимость, отслеживание успеха с уведомлениями
### 📚 Трубопровод RAG | RAG 管线








- **Chunking**: фиксированный размер, предложение, абзац, рекурсивный, markdown, скользящее окно
- **Embedding**: OpenAI, преобразователи предложений, расширяемые бэкенды
- **Извлечение**: гибрид (BM25 + вектор), слияние RRF, взвешенная комбинация
- **Переоценка рейтинга**: Оценка на основе очков, разнообразие MMR, кросс-кодировщик, судья LLM
### 🤖 Фреймворк агентов | Agent 框架
- **ReAct Agent**: Логическое мышление + Цикл действия с использованием инструмента
- **Система инструментов**: регистрация на основе декоратора, JSON Schema, валидация
- **Оркестрация**: последовательные, параллельные, дебаты, паттерны менеджер-работник
- **Память**: Краткосрочная, долгосрочная, эпизодичная, рабочая память
### 📊 Оценка | 评估
- **Подсчёт**: BLEU, ROUGE-1/2/L, семантическое сходство, F1, точное совпадение
- **Бенчмаркинг**: задержка, пропускная способность, стоимость, процент успешности под нагрузкой
### 🌐 API сервер | API 服务
- **FastAPI**: Совместимые с OpenAI INLINE14, вложения, RAG, конечные точки агентов
- **Промежуточное ПО**: логирование, ограничение скорости, идентификатор запроса, тайминг, CORS
