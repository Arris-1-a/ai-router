## అవలోకనం | అవలోకనం
**ai-router** అనేది తెలివైన LLM API మేనేజ్ మెంట్ కొరకు ప్రొడక్షన్-రెడీ పైథాన్ టూల్ కిట్. ఇది ఆటోమేటిక్ లోడ్ బ్యాలెన్సింగ్, ఫాల్ బ్యాక్, కాస్ట్ ఆప్టిమైజేషన్ మరియు సమగ్ర కొలమానాలతో బహుళ AI ప్రొవైడర్లు (OpenAI, ఆంత్రోపిక్, డీప్ సీక్, గూగుల్ మరియు మరిన్ని) రూటింగ్ అభ్యర్థనల కోసం ఏకీకృత ఇంటర్ ఫేస్ ను అందిస్తుంది.
**ai-router** అనేది LLM API అభ్యర్థనలను తెలివిగా నిర్వహించడానికి ప్రొడక్షన్-గ్రేడ్ పైథాన్ టూల్ కిట్. ఇది బహుళ AI ప్రొవైడర్లలో (OpenAI, ఆంత్రోపిక్, డీప్ సీక్, గూగుల్ మొదలైనవి) ఇంటెలిజెంట్ రూటింగ్ కు మద్దతు ఇచ్చే ఏకీకృత ఇంటర్ ఫేస్ ను అందిస్తుంది, ఇది ఆటోమేటిక్ లోడ్ బ్యాలెన్సింగ్, ఫెయిల్ ఓవర్, కాస్ట్ ఆప్టిమైజేషన్ మరియు సమగ్ర మెట్రిక్ పర్యవేక్షణను కలిగి ఉంటుంది.

## ఫీచర్లు | 功能特性
### స్మార్ట్ 🧠 రౌటర్ | 智能路由器
- **మల్టీ-ప్రొవైడర్ **: OpenAI, ఆంత్రోపిక్, డీప్ సీక్, గూగుల్ జెమిని, ఎక్స్ టెన్సిబుల్
- **వ్యూహాలు **: రౌండ్-రాబిన్, వెయిటెడ్, తక్కువ-జాప్యం, తక్కువ-ఖర్చు, అర్థశాస్త్రం, అనుకూల
- ** క్యాచింగ్ **: LRU + సెమాంటిక్ సారూప్యత డెడప్ కాష్
- **ఫాల్ బ్యాక్ **: సర్క్యూట్ బ్రేకర్, ఆటోమేటిక్ రీట్రై, మల్టీ-లెవల్ ఫాల్ బ్యాక్ చైన్స్
- **రేట్ లిమిటింగ్**: టోకెన్ బకెట్ అల్గారిథం, పర్-ప్రొవైడర్ & గ్లోబల్ లిమిట్స్
- ** కొలమానాలు **: జాప్యం, ఖర్చు, హెచ్చరికలతో విజయ రేటు ట్రాకింగ్
### 📚 RAG పైప్ లైన్ | RAG 管线








- ** చంకింగ్ **: స్థిర-పరిమాణం, వాక్యం, పేరాగ్రాఫ్, పునరావృత, మార్క్ డౌన్, స్లైడింగ్ విండో
- ** పొందుపరచడం **: OpenAI, వాక్యం-ట్రాన్స్ ఫార్మర్లు, విస్తరించదగిన బ్యాక్ ఎండ్ లు
- ** రిట్రీవల్ **: హైబ్రిడ్ (BM25 + వెక్టర్), RRF ఫ్యూజన్, వెయిటెడ్ కాంబినేషన్
- **రీర్యాంకింగ్ **: స్కోర్-ఆధారిత, MMR వైవిధ్యం, క్రాస్-ఎన్ కోడర్, LLM న్యాయమూర్తి
### 🤖 ఏజెంట్ ఫ్రేమ్ వర్క్ | Agent 框架
- **రియాక్ట్ ఏజెంట్ **: రీజనింగ్ + టూల్ వాడకంతో యాక్టింగ్ లూప్
- **టూల్ సిస్టమ్ **: డెకరేటర్ ఆధారిత రిజిస్ట్రేషన్, JSON స్కీమా, ధ్రువీకరణ
- **ఆర్కెస్ట్రేషన్ **: సీక్వెన్షియల్, సమాంతర, చర్చ, మేనేజర్-వర్కర్ నమూనాలు
- ** మెమరీ **: స్వల్పకాలిక, దీర్ఘకాలిక, ఎపిసోడిక్, వర్కింగ్ మెమరీ
### 📊 మూల్యాంకనం | 评估
- ** స్కోరింగ్ **: BLEU, ROUGE-1/2/L, సెమాంటిక్ సారూప్యత, F1, ఖచ్చితమైన మ్యాచ్
- **బెంచ్ మార్కింగ్ **: జాప్యం, నిర్గమాంశ, ఖర్చు, లోడ్ కింద విజయ రేటు
### 🌐 API సర్వర్ | API 服务
- **FastAPI **: OpenAI-అనుకూలమైన INLINE14, ఎంబెడింగ్స్, RAG, ఏజెంట్ ఎండ్ పాయింట్ లు
- **మిడిల్ వేర్ **: లాగింగ్, రేటు పరిమితి, అభ్యర్థన ID, సమయం, CORS
