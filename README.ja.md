## 概要 | 概要
**ai-router**は、インテリジェントなLLM API管理のための本番環境対応のPythonツールキットです。複数のAIプロバイダー(OpenAI、Anthropic、DeepSeek、Googleなど)間でリクエストをルーティングするための統一インターフェースを提供し、自動負荷分散、フォールバック、コスト最適化、包括的な指標を備えています。
**ai-router**は、LLM APIリクエストを賢く管理するための本番レベルのPythonツールキットです。 複数のAIプロバイダー(OpenAI、Anthropic、DeepSeek、Googleなど)間でインテリジェントなルーティングをサポートする統一インターフェースを提供し、自動負荷分散、フェイルオーバー、コスト最適化、包括的な指標監視を特徴としています。

## 特徴 |功能特性
### 🧠 スマートルーター |智能路由器
- **マルチプロバイダー**:OpenAI、Anthropic、DeepSeek、Google Gemini、拡張可能
- **戦略**:ラウンドロビン、加重、最低遅延、最低コスト、セマンティック、適応
- **キャッシュ**:LRU + 意味的類似性のデデアップキャッシュ
- **フォールバック**:サーキットブレーカー、自動再試行、多層フォールバックチェーン
- **レート制限**:トークンバケットアルゴリズム、プロバイダーごとおよびグローバル制限
- **指標**:レイテンシ、コスト、成功率のアラートによる追跡
### 📚 RAGパイプライン |RAG 管线








- **チャンク化**:固定サイズ、文、段落、再帰、マークダウン、スライドウィンドウ
- **埋め込み**:OpenAI、文変換器、拡張可能なバックエンド
- **回収**:ハイブリッド(BM25+ベクター)、RRF融合、加重結合
- **再ランキング**:スコアベース、MMR多様性、クロスエンコーダー、LLMジャッジ
### 🤖 エージェント・フレームワーク |エージェントフレームワーク
- **ReAct Agent**:推論+ツール使用を伴う演技ループ
- **ツールシステム**:デコレーターベースの登録、JSONスキーマ、検証
- **オーケストレーション**:連続的、並列、討論、マネージャーと労働者のパターン
- **記憶**:短期、長期、エピソード記憶、作業記憶
### 📊 評価 |评估
- **得点方法**:BLEU、ROUGE-1/2/L、意味的類似性、F1、完全一致
- **ベンチマーク**:遅延、スループット、コスト、負荷時の成功率
### 🌐 APIサーバー |API サービス
- **FastAPI**:OpenAI互換INLINE14、埋め込み、RAG、エージェントエンドポイント
- **ミドルウェア**:ログ、レート制限、リクエストID、タイミング、CORS
