## கண்ணோட்டம் | கண்ணோட்டம்
**ai-திசைவி ** என்பது புத்திசாலித்தனமான LLM API நிர்வாகத்திற்கான உற்பத்திக்கு தயாராக உள்ள பைதான் கருவித்தொகுப்பாகும். தானியங்கி சுமை சமநிலை, வீழ்ச்சி, செலவு தேர்வுமுறை மற்றும் விரிவான அளவீடுகளுடன் பல AI வழங்குநர்கள் (OpenAI, Anthropic, DeepSeek, Google மற்றும் பல) முழுவதும் ரூட்டிங் கோரிக்கைகளுக்கான ஒருங்கிணைந்த இடைமுகத்தை இது வழங்குகிறது.
**ai-router** என்பது LLM API கோரிக்கைகளை புத்திசாலித்தனமாக நிர்வகிப்பதற்கான உற்பத்தி-தர பைதான் கருவித்தொகுப்பாகும். இது பல AI வழங்குநர்கள் (OpenAI, Anthropic, DeepSeek, Google, முதலியன) முழுவதும் அறிவார்ந்த ரூட்டிங்கை ஆதரிக்கும் ஒருங்கிணைந்த இடைமுகத்தை வழங்குகிறது, இதில் தானியங்கி சுமை சமநிலை, தோல்வி, செலவு தேர்வுமுறை மற்றும் விரிவான மெட்ரிக் கண்காணிப்பு ஆகியவை இடம்பெற்றுள்ளன.

## அம்சங்கள் | 功能特性
### 🧠 ஸ்மார்ட் திசைவி | 智能路由器
- **மல்டி-வழங்குநர்**: OpenAI, மானுடவியல், டீப்சீக், கூகிள் ஜெமினி, நீட்டிக்கக்கூடியது
- ** உத்திகள்**: ரவுண்ட்-ராபின், எடை, மிகக் குறைந்த-தாமதம், குறைந்த செலவு, சொற்பொருள், தகவமைப்பு
- ** கேச்சிங்**: LRU + சொற்பொருள் ஒற்றுமை dedup தற்காலிக சேமிப்பு
- ** வீழ்ச்சி**: சர்க்யூட் பிரேக்கர், தானியங்கி மறுமுயற்சி, பல நிலை வீழ்ச்சி சங்கிலிகள்
- **விகித வரம்பு**: டோக்கன் பக்கெட் அல்காரிதம், ஒரு வழங்குநர் மற்றும் உலகளாவிய வரம்புகள்
- ** அளவீடுகள் **: தாமதம், செலவு, விழிப்பூட்டல்களுடன் வெற்றி விகித கண்காணிப்பு
### 📚 RAG குழாய் | RAG 管线








- ** சங்கிங் **: நிலையான அளவு, வாக்கியம், பத்தி, மீண்டும், மார்க்டவுன், நெகிழ் சாளரம்
- **உட்பொதித்தல்**: OpenAI, வாக்கியம்-மின்மாற்றிகள், நீட்டிக்கக்கூடிய பின்தளங்கள்
- ** மீட்டெடுப்பு **: கலப்பின (BM25 + திசையன்), RRF இணைவு, எடையுள்ள கலவையானது
- **மறுதரமை**: மதிப்பெண் அடிப்படையிலான, MMR பன்முகத்தன்மை, குறுக்கு-குறியாக்கி, LLM நீதிபதி
### 🤖 முகவர் கட்டமைப்பு | முகவர் 框架
- **React Agent**: பகுத்தறிவு + கருவி பயன்பாட்டுடன் செயல்படும் வளையம்
- **கருவி அமைப்பு **: அலங்கார அடிப்படையிலான பதிவு, JSON திட்டம், சரிபார்ப்பு
- ** ஆர்கெஸ்ட்ரேஷன் **: தொடர்ச்சியான, இணையான விவாதம், மேலாளர்-தொழிலாளர் வடிவங்கள்
- ** நினைவகம் **: குறுகிய கால, நீண்ட கால, எபிசோடிக், வேலை நினைவகம்
### 📊 மதிப்பீடு | 评估
- **மதிப்பெண் **: BLEU, ROUGE-1/2/L, சொற்பொருள் ஒற்றுமை, F1, சரியான பொருத்தம்
- ** பெஞ்ச்மார்க்கிங்**: தாமதம், செயல்திறன், செலவு, சுமை கீழ் வெற்றி விகிதம்
### 🌐 API சேவையகம் | API 服务
- **FastAPI**: OpenAI-இணக்கமான INLINE14, உட்பொதிப்புகள், RAG, முகவர் இறுதிப்புள்ளிகள்
- **மிடில்வேர்**: பதிவு செய்தல், விகித வரம்பு, கோரிக்கை ஐடி, நேரம், CORS
