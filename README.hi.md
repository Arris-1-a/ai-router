## अवलोकन | विहंगावलोकन
**एआई-राउटर** बुद्धिमान एलएलएम एपीआई प्रबंधन के लिए एक उत्पादन-तैयार पायथन टूलकिट है। यह स्वचालित लोड संतुलन, फ़ॉलबैक, लागत अनुकूलन और व्यापक मेट्रिक्स के साथ कई AI प्रदाताओं (OpenAI, Anthropic, DeepSeek, Google, और अधिक) में अनुरोधों को रूट करने के लिए एक एकीकृत इंटरफ़ेस प्रदान करता है।
**एआई-राउटर** एलएलएम एपीआई अनुरोधों को बुद्धिमानी से प्रबंधित करने के लिए एक उत्पादन-ग्रेड पायथन टूलकिट है। यह कई एआई प्रदाताओं (ओपनएआई, एंथ्रोपिक, डीपसीक, गूगल, आदि) में बुद्धिमान रूटिंग का समर्थन करने वाला एक एकीकृत इंटरफ़ेस प्रदान करता है, जिसमें स्वचालित लोड संतुलन, विफलता, लागत अनुकूलन और व्यापक मीट्रिक निगरानी शामिल है।

## विशेषताएं | 功能特性
### 🧠 स्मार्ट राउटर | 智能路由器
- **मल्टी-प्रोवाइडर**: ओपनएआई, एंथ्रोपिक, डीपसीक, गूगल जेमिनी, एक्स्टेंसिबल
- **रणनीतियाँ**: राउंड-रॉबिन, भारित, सबसे कम विलंबता, सबसे कम लागत, शब्दार्थ, अनुकूली
- **कैशिंग**: एलआरयू + सिमेंटिक समानता डेडअप कैश
- **फ़ॉलबैक**: सर्किट ब्रेकर, स्वचालित पुनः प्रयास, बहु-स्तरीय फ़ॉलबैक चेन
- **दर सीमित करना**: टोकन बकेट एल्गोरिथ्म, प्रति-प्रदाता और वैश्विक सीमाएं
- **मेट्रिक्स**: अलर्ट के साथ विलंबता, लागत, सफलता दर ट्रैकिंग
### 📚 आरएजी पाइपलाइन | RAG 管线








- **चंकिंग**: निश्चित आकार, वाक्य, पैराग्राफ, पुनरावर्ती, मार्कडाउन, स्लाइडिंग विंडो
- **एम्बेडिंग**: ओपनएआई, वाक्य-ट्रांसफार्मर, एक्स्टेंसिबल बैकएंड
- **पुनर्प्राप्ति**: हाइब्रिड (बीएम25 + वेक्टर), आरआरएफ संलयन, भारित संयोजन
- **रीरैंकिंग**: स्कोर-आधारित, एमएमआर विविधता, क्रॉस-एनकोडर, एलएलएम जज
### 🤖 एजेंट फ्रेमवर्क | एजेंट 框架
- **रिएक्ट एजेंट**: रीजनिंग + टूल के उपयोग के साथ एक्टिंग लूप
- **टूल सिस्टम**: डेकोरेटर-आधारित पंजीकरण, JSON स्कीमा, सत्यापन
- **ऑर्केस्ट्रेशन**: अनुक्रमिक, समानांतर, बहस, प्रबंधक-कार्यकर्ता पैटर्न
- **मेमोरी**: अल्पकालिक, दीर्घकालिक, एपिसोडिक, कार्यशील स्मृति
### 📊 मूल्यांकन | 评估
- **स्कोरिंग**: BLEU, ROUGE-1/2/L, शब्दार्थ समानता, F1, सटीक मिलान
- **बेंचमार्किंग**: लोड के तहत विलंबता, थ्रूपुट, लागत, सफलता दर
### 🌐 एपीआई सर्वर | API 服务
- **फास्टएपीआई**: ओपनएआई-संगत INLINE14, एम्बेडिंग, आरएजी, एजेंट एंडपॉइंट
- **मिडलवेयर**: लॉगिंग, दर सीमित करना, अनुरोध आईडी, समय, सीओआरएस
